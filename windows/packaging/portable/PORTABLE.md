# 星穹旅驿 · Windows 便携版规范

## 组成

ZIP 解压即可运行，目录结构：

```
星穹旅驿-2.0.1-windows-x64-portable/
├── xqly.exe                  # 已签名主程序
├── *.dll                     # 运行所需的 Flutter/VC 运行时 DLL（实际构建产物为准）
├── data/
│   └── design-tokens.json    # 双平台共享设计令牌
├── portable.flag             # 便携版标识：外壳据此选择数据目录与应用标识
├── Data/                     # 首次运行自动创建，保存用户数据
├── LICENSE / NOTICE.md
└── 便携版说明.txt            # 本文件的纯文本版
```

> **关于 MSIX**：便携版与 MSIX 安装版是两套独立包装。若某次交付采用 MSIX，
> 不会对同一份二进制同时声称它是「完全等价的便携版」；两者分别按各自包装能力构建与验证。

## 应用标识隔离

便携版与安装版默认使用**不同的应用标识**，避免共享数据造成冲突：

| 项 | 安装版 | 便携版 |
|---|---|---|
| 数据目录 | `%LOCALAPPDATA%\XQLY` | EXE 旁的 `Data\` |
| 窗口类名 | `XQLY_Win32_Window` | `XQLY_Win32_Window_Portable` |
| 单实例互斥体 | `Local\XQLY_SingleInstance_Installed_*` | `Local\XQLY_SingleInstance_Portable_*` |

因此两个版本可以同时运行、互不激活、互不覆盖数据。实现见
`runner/win32/main.cpp`、`system_integration.cpp`、`window.cpp`。

## 目录只读时的降级

启动时会写入探测文件 `.write-test`：

1. `Data\` 可写 → 正常使用；
2. `Data\` 不可写（例如解压到受保护目录或只读 U 盘）→ **明确提示**并切换到
   `%LOCALAPPDATA%\XQLY`，不静默失败、不丢数据；
3. 两者都不可写 → 弹出错误说明并退出，不产生半初始化状态。

## 不做的事

- 不创建开机启动、全局热键、文件关联或右键菜单扩展（这些只在用户明确安装扩展时启用）；
- 不写系统受保护目录，不修改 hosts、代理、DNS 或浏览器设置；
- 不注入其他进程，不安装捆绑软件；
- 不把用户数据写到安装目录来模拟全局安装。

## 退出与清理

- **退出并清理缓存**：设置中提供入口，执行前列出将释放的空间与影响范围；
  清理只针对 `Data\cache\`，**不会删除**收藏、同步库、阅读进度、书签与游戏存档。
- **清理用户数据**：单独入口，必须二次确认，列出具体目录与文件后再删除。
- **卸载**：退出程序后直接删除整个解压目录即可；若曾切换到
  `%LOCALAPPDATA%\XQLY`，需通过该入口一并清理。

## 更新

便携版支持「下载新版本并准备替换」：

1. 只接受 HTTPS 白名单更新清单；
2. 校验发布签名、版本、目标架构与文件哈希；
3. **更新前备份用户库**（`Data\` → `Data.backup\`）；
4. 退出进程后原子替换 EXE/DLL/data；
5. 启动自检失败时自动从 `Data.backup\` 恢复，绝不留下无法启动的半成品。

签名验证与下载链路见 `../sign.ps1` 与 `.github/workflows/release.yml`。
